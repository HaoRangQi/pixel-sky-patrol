# 飞行舒适度实施计划

- Goal：实现[明确行为](../specs/2026-11-21-flight-comfort.md)，解决用户感受不到速度差和普通转向眩晕。
- Architecture：`65_app.js`单独管理设置／输入手势；共享飞行读取可选配置和翻滚分量；`42_combat.js`只在敌机速度路径应用倍率。
- Tech Stack：现有JS飞行模型、HTML暂停菜单、Node VM、Chrome CDP。
- Baseline：现有暂停调速设计、最新干扰弹修复、`40_game.js`／`64_scene.js`／`65_app.js`／座舱绘制及已有回归。
- Compatibility：根入口默认112/204m/s和旧操纵不变；新版保持Q、干扰弹、武器、触屏、暂停冻结与平滑恢复。旧的500以上加力和鼠标默认开启按本轮要求退出。
- Verification：新行为先红后绿，原入口公式回归、双构建、全Node、真实Chrome设置与AD手势／Shift／鼠标／敌机／三尺寸布局及视觉对照。

1. 复用 `tools/test_sky_speed.mjs` 实际生命周期夹具补新需求失败测试，更新有意改变的新版默认及边界期望；保留原入口与共享公式的比较。
2. root更新新版暂停菜单500封顶、保留加力余量、默认关鼠标和敌机倍率；在原模型加入可选的座舱舒适响应、速度收敛和翻滚分量，适配层负责半滚手势和动画。仪表、武器位置及相机使用一致翻滚姿态。
3. `enemy_speed`拥有 `src/42_combat.js`和新增敌机速度测试，完成独立倍率路径与原默认精确兼容。root集成页面参数，不重复实现敌机逻辑。
4. root检查诊断数据并集成速度状态反馈；使用独立Chrome验证100/500节与默认Shift的真实位移、场景投影和连续帧，普通座舱AD慢转，正确手势翻转／翻回和误触不翻，暂停控件与触屏保留。
5. 全量回归、视觉检查、独立契约审查、文档更新。使用work_state持续记录结果，不提交或发布。

共享飞行文件已905行，本轮仍由原速度／姿态块承载相关可选参数，不引入另一个飞行模拟器；适配层仍低于800行。敌机模块改动由独立owner完成，避免与玩家状态机冲突。
