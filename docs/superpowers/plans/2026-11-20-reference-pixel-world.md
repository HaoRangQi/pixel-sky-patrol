# 参考湖谷像素画风 Implementation Plan

> 下列 Task 1–5 是此前版本的实施记录：其中的单湖盆、旧出生点和强制高抛弹道已经被后续实飞修正取代，不是当前验收要求。当前路线、弹道、回放及复验结果见 [新版验收记录](../../../sky-patrol/VERIFICATION.md)。工作树不推送、不自动合并。

**Goal:** 在已存档版本的新分支上，用真实可飞湖谷和夕照像素渲染复刻参考画风，保留操作、改进弹道，默认从机身正后方看机尾。

**Architecture:** 独立入口插入地图、Shader、森林与镜头适配；共享战斗引擎负责双方实体机枪弹、锁定追踪和无锁抛物线导弹。地图在上传纹理与森林初始化之前更新同一张 CPU 地图；Shader 在 Renderer.init 前执行。不用静态背景冒充实景。

**Tech Stack:** 原生 JavaScript、WebGL2 / GLSL ES 3、Canvas2D、Node test、独立 Chrome CDP。
