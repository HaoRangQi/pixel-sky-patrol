# 准星近场对齐与环绕伴飞

Goal：用户最新截图中的近场机炮弹点进入实际准星射线；僚机围绕玩家伴飞，不长期锁在机尾。两项都以连续实际画面和真实运动回归验收。

Architecture：战斗层仍持有发射、飞行与命中，HUD 投影实体；新版屏幕射线为实体炮弹的起点，机鼻保留枪口火光。空中无交点时准星代表随载机移动的射击方向，速度按向量继承载机运动；射线实际命中目标或地形时，对该真实世界点求发射速度，保持瞄准所见处可命中。锁定对象不参与解算。相机必须在发射前完成本帧更新。僚机在 `44_ai.js` 持有环绕航线、前馈运动及现有资源状态。

Tech Stack：已有 JS / Canvas2D / WebGL2、Node 实体回归和独立 Chrome 验收；无新运行依赖和后台服务。

Baseline/Authority：用户 00:04 的错位截图与后续“我是太阳、他是卫星”的要求；`PRODUCT.md`、准星资源笔记、僚机接入笔记。静止相机测试不足：旧默认 100 节时 0.05 秒的近弹下偏 18.21 逻辑像素；500／1500 节移动相机时 0.5 秒下偏 19.55／54.47 像素。既有 `formation` 是移动位置的追逐，没有前馈玩家运动速度。

First principles：可见准星、实体射击与命中必须一致；伴飞要实际覆盖玩家四周。原机鼻必须作为实体起点和“玩家空速标量加到瞄准方向”的实现习惯可被替换，保留机鼻视觉反馈、旧入口和真实碰撞。不会把 HUD 弹点搬去准星、让已发子弹跟随镜头转动，也不通过瞬移摆放僚机。

Compatibility：旧入口未启用 `gunEffectiveRange` 时保留机鼻起点、原弹道和速度。新版 900 米有效射程、伤害、弹量、补给不变。僚机继续 80 盾／36 发／18 秒补给、近距低输出、真实转向与避地、友伤关闭、开关防刷。近场起点由准星射线在机鼻前向平面的交点确定，与机体安全分离；世界交点分支只承接现有真实射线碰撞。

TDD Route：strict。ArchitectureReviewRequired：yes。CanonicalOwner：`42_combat` 的发射解算、`40_game` 帧时序、`44_ai` 伴飞；所有者不迁移。大文件只添加有界发射解算，移除旧标量/远距视差假设；不新增通用框架。

1. 在 `test_gun_sight_resources` 增加 100／500／1500 节真实平移相机的近弹准星误差，覆盖出生、前900米、飞出后转向独立；保留真实世界目标／地形射线命中。先看失败，再改发射起点与速度计算、相机时序；同步提前量与自然追击控制。
2. 在 `test_sky_wingman` 增加移动玩家四周的真实环绕覆盖、机尾停留占比、距离／单步位移、转向与加速恢复。替换 follow/regroup 固定后槽与追逐正弦目标，使用半径约180米的水平环、玩家速度和环绕切向速度前馈、有限位置误差校正；补给使用更宽环，交战与脱离优先级继续保留。
3. 双构建，相关实体测试，再实际 Chrome 记录近弹与准星的屏幕误差和 Canvas 亮头、原生追击命中；记录僚机60秒以上的方位、真实移动、四周伴飞帧，以及转向和资源回归。
4. 全量回归、笔记同步与校验、实际截图读回、服务当前HTML核对，关闭专用Chrome和临时服务。只保留既有8765预览。

Repair/Retirement：新版不再用机鼻到900米单点收敛作为全程可见准星的承诺；旧起点只因原入口合同保留。默认僚机移除固定机尾槽和没有移动速度前馈的追逐逻辑，补给亦采用环绕；旧战斗/资源所有者继续有效。相机每帧只更新一次，移到发射之前，不再同时维护上一帧瞄准与本帧绘制。

Risks：真实世界目标在玩家前进、转向时会在屏幕上移动，已发弹体应继续追随原世界路径而不是当前准星；验收要比较对应世界目标位置。纯方向射击在平稳飞行中应与准星一致。环绕允许短时间经过后方，但不能长期停在那里；极端转弯或加力时允许真实归队过程，不瞬间贴回环上。
