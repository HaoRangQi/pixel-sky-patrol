# 可调战斗难度与有限反制

Goal：消除锁定后可靠一两发清场的单调循环，提供轻松／标准／挑战与逐兵种可调有限干扰，让玩家可用机炮、消耗诱饵、抓脱离窗口主动破局；默认航程更有持续交战和成就感。

Baseline：现有无人机72、战斗机130、运输机390耐久，玩家导弹130伤害；前两种无干扰，运输机2次必定成功。近距尾追无限直飞，阻止敌机形成反击。三关队列4／5／6，初始3／4／4活动单位，迅速补充。现有设置、帧时序、真实机炮射线、环绕伴飞与有限资源作为兼容底线。

Design：默认标准。兵种默认1／2／3次干扰，成功率45／65／75%；轻松1／1／2、25／40／55%；挑战1／2／3、60／75／85%。设置可逐种在0–5次、0–100%调整，改动标为自定义，沿用所选档的战术和增援。所有战斗设置在新航次快照，暂停改动明确下次出航生效，不给当前敌人刷资源。重开保留本页设置，刷新回标准。

Mechanics：每次应对消耗一发，不论成功与否；单枚导弹只抽签一次，活动诱饵短窗口可应对同轮齐射，不按帧重抽。真实导弹成功改向实际诱饵，失败继续追原目标。冷却有限且库存不回复，机炮不触发干扰。没有新版规则的原入口沿用旧运输机2次必定成功合同。

Tactics：无人机／战斗机保持入场与可追击速度；900米内被尾追一段后发出约0.9秒准备脱离提示，再侧向转弯并向玩家侧后方重整反击。标准无人机8秒、战斗机6秒，轻松更长、挑战更短；不增加瞬移、速度上限、转弯能力或无预兆反转。原四秒机炮回归和自然等两秒射击必须继续成立。

Pacing：轻松沿用4／5／6；标准增加为6／8／10，挑战8／10／12，其中终关增加运输／护航混合增援，保持3关结构、有限同屏单位和原胜利／继续迎击入口。玩家武器、耐久和僚机输出不削弱。不以空白等待或大幅加血拖长流程。

Architecture：`43_defense.js` 持有规则预设、快照构造、敌机反制与战术；新 `sky-patrol/66_difficulty.js`（在65之后装载）独立持有原生设置UI同步和难度快照，不继续扩写800+行适配文件。65只接入出航快照／队列和同步；55读状态绘制诱饵结果、剩余次数、脱离预兆与目标剩余干扰。旧运输机专用反制实现被同一有限反制所有者取代。无外部调用、依赖或后台服务。
