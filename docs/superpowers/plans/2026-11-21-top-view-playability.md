# 俯瞰可玩范围、实时加速、R回正与连续翼尖线

当前任务在 `feature/reference-pixel-world` 本地实施。用户截图明确为俯瞰，要求缩小机身、看清敌情、解决加速地景位移不变、R有过程地回正、翼尖线持续存在。沿用[已实现飞行合同](../specs/2026-11-21-flight-comfort.md)，不重新发布主分支。

## 证据与边界

原俯瞰机位只高26米，飞机高度平面视场约49×27米，地面却在镜头下约700米，导致飞机独占画面且敌人只能靠很淡的边缘数字寻找。新版在 `64_scene.js` 提高至85米、固定1.10rad，机长约占画高10%，北向不变。原入口26米／.95rad不变。

正常60FPS真实墙钟速度为112m/s巡航、加力稳定257m/s；CPU64倍限速时实际4.37FPS却只推进约20.5%的墙钟时间，Shift后2.68FPS只推进13.4%，HUD仍报告52／38FPS。根因是RAF丢弃超过50ms的时间，FPS又使用截断时间。由共享 `60_main.js` 用真实elapsed计帧率与质量，最多恢复.5秒并拆成不超过.05秒的模拟子步；后台恢复不追赶。速度、FOV和场景尺度均不做加速特效。

R接管当前模型总滚转与俯仰，用1.6秒缓动回水平，保持航向、视角、任务与实际前进；半滚和Q中途也能接管。恢复期忽略方向输入及新的滚转，但保留按键状态，暂停冻结，重开清理。失败页R仍重新起飞，原入口飞行R保持原合同。

新版玩家增加 `continuousTrails`，复用真实翼尖的世界坐标采样与寿命，所有速度／视角持续采样。座舱不将物理上位于机后的线画到仪表前。
