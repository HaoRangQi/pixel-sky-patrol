# 缩紧锁定与恢复真实机炮炮口

目标：锁定必须更靠近准星，画面不再被大圈占据；炮弹从实际机鼻炮口出生，而不是准星前方的空中点。用户两张截图是本轮验收输入。

基线：`playerLockAim` 追尾／座舱半径74、俯瞰92，维持圈1.34倍；锁定目标环半径约30，确认回声最大40。`playerGunSolution` 把机鼻起点投到准星射线上，追尾／座舱实际离炮口3.51／3.36米。旧测试要求出生与全程投影误差低于0.35像素，误把这一游戏化起点当成正确合同。

决定：新版正式玩家使用 `lockRadius=38`，俯瞰为47.5，维持圈1.18倍；原入口不携带该配置，保留原锁定合同。新版目标环约16像素，移除外扩确认回声，标签按22像素的占用范围避让。锁定时间、距离、诱骗率和敌方资源不变。

机炮从已有机鼻下方炮口（前4.9米、下0.62米）出生，位置按本帧可见机体姿态计算，火光与弹体共用该点。空中方向射击以900米准星射线点校准炮口视差，再按向量继承载机速度；真实静止目标／地形交点仍按实际深度解算。不读取锁定目标吸附，不搬HUD像素、不隐藏近弹。近弹与准星之间的视差是有来源的实际飞行，到校准距离收敛。超程下坠、实体扫掠、弹量、补给、帧时序和伴飞保持。

第一性原则：真实炮口与“出生即在相机准星射线”无法同时成立，后者退出。不能把前轮全程重合误差阈值搬到新合同。修复在生产者，绘制仍投影真实实体。
