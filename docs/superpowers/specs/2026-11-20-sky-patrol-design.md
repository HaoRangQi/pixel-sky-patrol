# 天际巡航：参考站界面重制

## 目标
在 `feature/sky-patrol-ui` 开发新的中文可玩空战入口 `sky-patrol/index.html`。参考用户提供的 Dusk Patrol 公开页面的界面结构，不复制品牌、源代码或素材。原版根目录 `index.html` 和 `src/` 保持不变；不自动提交或推送。

## 视觉
2026-11-20 重新浏览了参考站并保存 `shots/reference_ui_current.png`：1440×900 页面约40px留边，顶部图标/游戏名、声音/全屏按钮；大幅有边框的飞行画面；左上斜体像素双行标志和地图字幕；顶部罗盘；左下高度/速度；右下镜头按钮；画布外底部操作提示与导弹余量。

新作使用原创 `SKY / PATROL` 像素字标和中文名“天际巡航”，保持上述层级与密度。使用深石墨灰、暖白、适量杏橙强调，不将橙色铺满背景。保留绿色秋林、少量黄叶、岩雪过渡、中性天光，不恢复夕阳与刺眼太阳。

## 功能与边界
- 开始界面展示实时飞行场景，提供“自由巡航”和“开始截击”；巡航不生成敌机、地面威胁或补波，忽略战斗伤害但仍可撞地；截击复用完整战斗波次。不增加账号、商店或外部依赖。
- 复用已验证的稳定飞行、三视角、桶滚、机炮、导弹、云下作战，避免重写物理。
- 页面按钮：开始/暂停/恢复、声音、全屏、镜头；底栏保留与真实输入一致的提示。
- 默认中文；键盘、鼠标、触屏控件可达，按钮点击不穿透为开火或操纵。
- 大屏适度留边，窄屏收缩字号和控制栏，尊重安全区域；不裁掉主按钮。
- 独立构建器拼接共享模块和新版界面层，生成可直接用 file URL 打开的单HTML。

## 模块与验证
独立 shell 负责网页外壳和锚定布局；新版 UI 负责稀疏 HUD/菜单；新版 app 负责 DOM 控件与引擎状态同步；构建器由主会话统一整合。各执行上下文只编辑独占文件。

先写并运行缺失入口的 RED 测试，再构建新版并检查共享源码未变、内联脚本语法与确定性。实际 Chrome 操作开始、镜头、射击/导弹、暂停恢复和声音，检查 console/GL 错误；截图须读取目视核对，并测桌面和窄屏。全屏若 headless 环境不支持则如实记录，不当作通过。旧版飞行/导弹测试继续回归。
