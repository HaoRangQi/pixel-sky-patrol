# 新版地形画风纠偏：按参考复刻

## 问题与验收标准
用户反馈：“地形画风差异很大，说了复刻”。此前交付只使外壳接近，旧地图和渲染仍是另一套视觉；功能回归通过不能证明画风接近。

以 `shots/reference_ui_current.png` / `shots/reference_low_pass.png` 和新版同尺寸、追尾、默认开场截图逐项对照。必须从地图宏观结构、材质色块和植被形态三层重做，不能仅换取景点、调滤镜、压低分辨率或加一层噪点。

## 直接执行的方向
- **地图**：连续宽湖湾占据画面中下部，弯曲岸线绕过前景右侧坡地；中景有低岛/半岛；左右山体围合、远处有层叠谷口，避免当前零碎小坑湖与遍地同尺度圆包。
- **岸水**：蓝青深水、较亮青绿浅水、窄柔和亮岸三级连贯带；波光沿水面稀疏分布，不出现全屏白点或纯黑水。
- **地面**：有限的低对比草甸色阶与世界空间小斑块，结合坡面与谷地，不使用平滑渐变大胶泥山坡；不以等高线条纹替代纹理。
- **林群**：针叶、圆冠落叶树的外形和大小可辨，成片但有草地间隙；绿色为基底、金黄/赭红秋树形成群落，不再一整片黑绿密林。
- **空间**：近中远明度/对比逐层降低，山体偏蓝灰/紫灰；地表、植被与云使用一致的像素光照语言。
- **像素**：世界采用接近参考的逻辑像素尺度与有限色阶，低对比有序抖色只混相邻颜色；UI文字保持清晰，不把此前令人不适的高亮白点恢复回来。
- **既往明确约束**：不画巨大刺眼太阳，不铺满屎黄色，不破坏稳定飞行、武器、中文与三视角。

## 隔离与验证
只改 `sky-patrol/` 和新增验收脚本；原版根 `index.html`、`src/` 不变，不提交或推送。地图CPU高度查询、森林落点、Shader纹理必须指向同一张新地图，不能出现画面地形和碰撞高度不一致。

先保留纠偏前截图，再写地图/材质的可运行断言。实际Chrome构建后截图与参考并排目视，至少默认追尾、低空追尾、座舱、俯视四类；最后回归飞行与战斗。结论应明确剩余差异，不宣称像素级一致。
