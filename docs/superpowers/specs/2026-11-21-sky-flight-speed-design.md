# 天际巡航：暂停调速

日期：2026-11-21。用户已确认「可以暂停调参」，采用此前提出的暂停菜单方案；不添加飞行中加减速按键。

已实现，结果见 [验收记录](../../../sky-patrol/VERIFICATION.md)；[实现边界与理由](../../../.agents/notes/implemented/feature/2026-11-21-paused-player-speed.md)。

本设计保存首轮行为；本轮用户进一步要求的新版500节封顶、默认500节加力、鼠标默认关闭与敌机参数，以[飞行舒适度设计](2026-11-21-flight-comfort.md)为准。

## 行为与范围

- 新版「航程暂停」增加两条原生滑块与实时节数：巡航速度 100–350 节、加力上限从当前巡航速度到 600 节，步长 1 节。提高巡航速度超过原加力上限时，同时提高上限，始终保持巡航不大于加力。
- 初始值仍是原始 112／204 m/s，界面四舍五入为约 218／397 节；不因显示取整改变原值。「恢复默认」还原原始精确值。
- 暂停时修改只更新目标参数，不改变位置、当前空速、燃油或仿真时间。继续飞行后按原有巡航收敛和加力加速度过渡；降低上限也平滑减速，不瞬间截断空速。
- Shift 与触屏加力继续受燃油限制；松开后回到设定的巡航速度。HUD、座舱速度表和位移均使用实际空速。
- 设置保留在当前页面，重开或切换截击／巡航使用所选巡航速度起飞；返回待命不改变演示飞行，刷新页面恢复默认。不添加 localStorage、预设或新设置页。
- 根入口不提供设置、默认飞行行为保持不变。不调整相机、飞机模型、HUD 布局、武器、耗油率或敌机速度；俯瞰拉宽是另一项工作。

## 实现边界

- 复用新版 `00_shell.html` 的暂停弹窗；范围控件、可见单位、关联标签和恢复默认按钮沿用现有暗色样式。短横屏允许弹窗滚动，所有控件始终可到达。
- `65_app.js` 管理当前页面参数，并在创建正式玩家和暂停调整时写入玩家的 `cruiseSpeed`／`burnSpeed`。不直接改当前 `speed`。
- 共享飞行模型读取玩家参数，未设置时回退到原速度常量；在高于新上限时复用现有减速阻尼。相机仍使用原始常量作为原有视场角基准，避免调参额外改变镜头。
- 新版座舱油门仍反映加力输入；空速表在加力上限超过现有刻度时扩大指针量程，实际空速仍来自 `p.speed`。
- 暂停焦点循环包含滑块和按钮；滑块方向键使用浏览器原生行为，不进入飞行快捷键。M 仍可切换音效。Esc 可从滑块恢复，恢复时清除输入与隐藏控件焦点。

## 验收

1. 默认值与未调整时的逐帧速度、燃油、位移不变；根入口回归通过。
2. 两项设置、上下界、巡航与加力联动、精确恢复默认和当前页面重开／换模式保留通过测试。
3. 暂停期间无仿真变化；恢复后加减速连续，达到正确巡航／加力值，松开加力与燃油耗尽仍回巡航。
4. 键盘 Tab／Shift+Tab 在弹窗内循环，方向键真实调整数值且不操纵飞机，Esc／继续按钮正常恢复，无粘键。
5. 独立 Chrome 验证 1440×900、390×844、844×390；检查读数、滑块、默认按钮与滚动可达性，并保存暂停菜单截图。
6. 重建两入口、运行全量 Node 测试与相关浏览器用例，记录结果与未测边界。
