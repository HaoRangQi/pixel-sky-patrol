# Agent Note: 音量滑轨、武器离架点与机身轮廓遮挡

Status: implemented

本篇的离架速度测量对应 2026-11-22 版本。新版高速射击现已继承发射载机速度，见[近距机炮与高速弹道](2026-11-23-close-range-gunnery.md)；本篇音量、挂点、机身轮廓遮挡和原入口合同继续适用。

## Problem

八项实机反馈里，下面四点落在共享引擎和 2D 覆盖层，而不是页面设置层：

- 声音只有开关，没有可调的默认音量，用户认为整体偏小。
- 同帧按 F／E 时导弹看起来比机炮更早落地；需要按真实弹体运动核对离架速度、持续推力和重力下坠，而不是只比配置上限。
- 截图里一块灰黑色椭圆压在机背上，像导弹落点痕迹穿模。根因是焦痕、地面阴影和特效画在没有深度缓冲的 2D 覆盖层上，按屏幕点整团判定后仍会把像素盖到机身上。
- 机炮与四枚导弹都从机身中线附近射出，看不出翼下挂架。

## Decision

音量是独立状态，与音效开关并存。滑轨 0–100% 直接映射主增益：默认 55% 等于旧版总增益 0.55，100% 为 1.0，0% 调度 `0.0001` 静音但不改变 `G.sound`／`AudioSys.enabled`，便于保留开关语义。共享默认值在 `10_core.js`，新版页面在 `65_app.js` 中同步回滑轨。

机炮口保持在机鼻下方 `+4.9 fwd / -0.62 up`，中线不偏。导弹按 `wingRailPosition(p, slot)` 轮流取四个挂点：左右交替 `±2.2`／`±3.25` 侧向，`-0.52` 下沉，前向 `0.8`／`2.15`。渲染使用同一 `renderBasis`，桶滚时挂点跟着画面机翼走。

导弹离架速度 `MISSILE_PLAYER_SPEED = 820`，持续推力加速到 `1000`，重力 `16`；机炮离架 `max(GUN_BULLET_SPEED, p.speed + 35)`，重力更高。两者从不同物理点出发，所以比较按各自离架点的前向距离和下坠。

2D 覆盖层的机体遮挡取机鼻、双翼尖与机尾的真实投影四角（翼尖按翼面后缘取 `fwd -1.9`），随本帧滚转和俯视偏航移动，缓存按 `G.time` + `G.view` 失效。焦痕、爆点、地面阴影用 `Path2D` + `evenodd` 把该轮廓从整屏里挖掉，轮廓向外扩 1.5 像素吸收裁剪抗锯齿；没有 `Path2D` 的环境退回整团绘制。焦痕和地面阴影不再用中心点整团剔除，只有中心深度与机身接近的导弹、曳光仍走中心点判定。

## Alternatives considered

继续用固定椭圆挖空改动最小，但俯视和滚转时椭圆比真实机翼窄、比机身短，翼尖和机鼻两侧仍会漏出焦痕像素；实测轮廓内仍有数十像素差异。

加大椭圆就能盖住漏点，但会顺带遮掉机身外本应可见的地面痕迹，而且换视角后比例不对。

把焦痕移回 WebGL 深度缓冲需要新的贴花渲染通道，改动面远大于 2D 剪裁，暂不采用。

只提高导弹配置上限而不改离架速度和推力，测速仍会出现“导弹离架更慢”，所以按真实弹速链路修正。

## Consequences

视野稳定的合同不变：加力仍靠真实世界位移体现，不动地形、不加风线。代价是 2D 覆盖层多了一次轮廓投影与一次 `Path2D` 裁剪，逐帧只在机体可见时发生，并按时/视角缓存。

机身轮廓是近似四角形，比真实像素模型略宽；对“遮住压在机身上的痕迹”这个目的足够，但不会精确到座舱盖边缘。
