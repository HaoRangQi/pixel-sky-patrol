# Agent Note: 窄锁定圈与真实炮口出生

Status: implemented

## Problem

用户截图指出锁定环太大、机炮亮点像凭空出现在准星附近。捕获范围实际为追尾／座舱74、俯瞰92个逻辑像素，保持圈扩大到1.34倍；目标环约30像素，确认回声最大约40。敌机离准星较远也能获得制导，装饰圈还占据大块画面。

[前轮近场射线](2026-11-24-gun-ray-projection.md)为了消除所有深度的准星偏差，把实体起点投到相机射线上。追尾与座舱中，这个点分别离实际炮口3.51／3.36米。旧验收要求刚出生和整个平直段都与准星重合，验证了这个游戏化起点，却没有验证炮弹必须从飞机离架。

## Decision

### 捕获更窄，保持只留小幅容错

新版正式玩家带 `lockRadius=38`；追尾／座舱捕获38，俯瞰光标捕获47.5，维持范围分别44.84／56.05。`playerLockAim` 与 `lockTargetScore` 仍是获取、保持及发射复核的同一所有者。越界当帧按E发射不沿用旧锁定；短时进度保留、云层／地形遮挡和有效距离继续原合同。锁定时间仍为0.8秒。

锁定目标的外环约15–16像素，括号8、进度环11，外侧刻度最多21；新版不再绘制扩张确认回声。`skyDefenseTargetReadouts` 按22像素留位，血条和身份文字继续可读。无 `lockRadius` 的原入口保留74／92及1.34倍的获取／维持合同和原标记。

### 炮弹与火光从同一个机体炮口出发

`firePlayerGuns` 从本帧可见机体姿态确定机鼻炮口：前4.9米、下0.62米。弹体和火光共用这个位置。`playerGunSolution` 不再生成相机射线上的替代起点；空中方向射击从炮口朝900米准星射线点校准，再以 `炮口方向×720 + 载机机头速度向量` 发射。既有静止世界目标／地形交点使用真实深度解算，运动目标继续需要相对提前量。

近处炮弹先在机身前方，随后沿实体路径接近准星；炮口与相机之间的视差不能被隐藏或搬像素来抹平。900米是方向校准基准，不再承诺各速度、各深度的弹点全程贴准星。已发弹体保持自己的世界方向，不随之后转向或锁定拐弯。

平直时间仍按900米和发射世界速度换算，重力、寿命、扫掠碰撞、伤害、弹量和补给保持。原入口未启用 `gunEffectiveRange` 时仍用原飞行姿态的机鼻与方向，不受新版可见机体姿态选择影响。前轮“更新相机与已有弹体之后再允许新弹出生”的完整帧时序保持；原生F按下的即时开火则必须在步进之前取出生帧，不能把推进一帧后的样本叫出生。

### 验收以来源和连续运动为准

实体回归直接比较出生点与炮口，并检查俯仰、侧倾和实际可见姿态。平直段随动相机检查误差持续减小、速度向量朝向校准点；不延长 `flatTime` 来满足断言。真实静止目标／移动提前量、地形、资源和原入口仍有独立合同。

Chrome记录实际按F当帧、0.05／0.1／0.25秒和连发，覆盖追尾、座舱、手机横竖屏；取真实弹体投影与Canvas亮头，不修改弹体或渲染坐标。窄圈验收用原生WASD把自然生成的敌机带到准星附近，再用D转出、E发射，不摆放目标或强制锁定。

## Alternatives considered

只缩小装饰圈最省改动，但实际获取和保持仍很宽，不能满足难度平衡，因此同时收紧真实判定。

保留相机射线起点可以维持出生零误差，却正是“空中凭空出现”的原因。真实炮口与相机射线在所有深度重合不能同时成立，本轮退出后者。

画一条连接炮口与准星的假线能强化来源，但不能改变真实弹体从空中出生，也会重新产生长光柱。现有活弹短历史足以显示真实离架路径，不增加另一套视觉弹道。

## Consequences

锁定更依赖手动瞄准，偏到原圈边缘不再白送制导；预设难度、敌方干扰库存与玩家资源不额外削弱。近弹有合理的炮口视差，收益是实际来源和运动一致；使用机炮仍需追近、瞄准移动提前量。

发射与锁定仍在 `42_combat.js`，标记仍在 `50_ui_hud.js`，新版配置在 `65_app.js`，标签避让在 `55_ui.js`。移除准星射线替代起点和新版外扩回声，退役出生／全程零误差断言；没有新运行模块、依赖或后台服务。大文件的既有职责不迁移，本轮只替换有界公式和尺寸；后续若再扩火控，应提取完整所有者，而不是在HUD累加补丁。

历史笔记审计：[近场射线](2026-11-24-gun-ray-projection.md)的起点决定被本篇取代，向量继承与帧时序继续有效；[准星与资源](../feature/2026-11-23-gun-sight-wingman-resources.md)继续持有补给和活弹历史；[近距尾追](2026-11-23-close-range-gunnery.md)继续持有射击窗口；[战斗难度](../feature/2026-11-24-combat-difficulty.md)继续持有兵种反制与编制。均为部分重叠，互链保留独特理由，不归档或删历史依据。

## Verification

新增合同在修复前13项失败；修复后相关163项、最终完整384项通过。真实Chrome34帧中16个出生样本与实际炮口的世界距离误差为0；自然目标在1.14像素偏差处完成锁定，D转至48.37像素时脱锁且E发射无锁。8颗超程弹头实际绘出并保留下坠，运行异常为0。

综合Chrome16阶段116项检查通过，自然敌机约8.13秒进入566米，辨认两秒后约10.63秒首次机炮命中。专用Chrome、临时profile和验收服务均退出。完整回归及截图见[当前验收记录](../../../../sky-patrol/VERIFICATION.md)。
