# Agent Note: 近距尾追的连续机炮窗口与高速弹道

Status: implemented

本篇继续持有防御关近距航线与高速弹速继承。机炮当前按屏幕准星校准视差，900 米内平直、超程后受重力，有限弹量和提前量提示见[机炮准星与资源闭环](../feature/2026-11-23-gun-sight-wingman-resources.md)；下文立即重力补偿与旧浏览器瞄准方式仅对应前轮诊断。

新版机炮从[真实炮口](2026-11-24-lock-muzzle-correction.md)出生，向量空速继承和随动帧时序沿用[前轮射线解算](2026-11-24-gun-ray-projection.md)；本篇标量空速相加继续只描述前轮实现，导弹与防御航线合同保持有效。

防御关当前在持续尾追达到难度窗口后加入 0.9 秒预兆、侧脱和前方重整反击，见[可调难度与有限反制](../feature/2026-11-24-combat-difficulty.md)。下文“被追近时同向脱离”继续描述窗口之前的机动；玩家仍保有连续的辨认和机炮机会。

## Problem

玩家追到约 566 米、已经能看见并锁定敌机，却在准备开炮时与目标迎头掠过，转弯也追不上。旧验收只约束敌机速度和最小转弯半径，没有证明实际可持续追击或用机炮命中。固定步进复现中，500 节迎头交会约 1.32 秒便失去机头前方目标；即使同向追到 566 米，敌机也会掉头迎着玩家转入，500 节无人机／战斗机的小角度窗口分别只有约 1.82／1.48 秒。

第二个独立问题是新版机炮速度使用 `max(720, 玩家速度 + 35)`。1500 节时炮弹相对载机只快 35 m/s，配合有限寿命和重力，无法支持高速尾追点射。导弹和僚机机炮也共享该高速离架约束。

## Decision

`43_defense.js` 持有防御飞机的入侵航向和被尾追时的航线。无人机、战斗机以玩家当前航向进入前方空域，保留原生成位置和真实实体；运输机继续原投放航线。玩家位于敌机尾后、敌机也处在玩家前方且距离小于 1800 米时，飞机沿当前航向同向脱离，保持高度，不再把玩家身位作为转向点。离开这些条件后恢复既有巡逻、交战或脱离逻辑。

近距速度按预计交会时间计算，目标为 `玩家当前空速 - max(0, 距离 - 180米) / 4秒`，下限沿用原兵种巡航倍率，上限为玩家当前空速的 95%，用既有阻尼连续收敛。远处仍可迅速追近；只在接近机炮区时减少闭合速度。转弯半径、地形避让、攻击冷却与运输机任务保持各自原有约束。

新版玩家机炮离架速度为载机当前速度加 `720 m/s`；导弹离架为载机速度加 `820 m/s`，上限为发射时载机速度加 `1000 m/s`。离架后弹体按自身速度、重力和推力积分，不再跟随载机后续姿态或加减速。僚机机炮使用相同的载机速度继承。原入口没有 `flightComfort` 时保持原有离架合同。

## Alternatives considered

进一步降低敌机最高速度可以缩小同向追近所需时间，却会增加迎头闭合速度和尾追超越风险，不能替代航线修复。

只扩大锁定圈或增加转向上限容易让自动检查重新通过，但敌机仍会穿过玩家，玩家仍没有辨认、瞄准和按下机炮键的时间。锁定范围和玩家手动转向在本次保持原合同。

沿用旧模式的 2.6 秒近掠直飞能稳定航向，却不能避免对头航线的高速交会。旧近掠规则继续只服务旧模式；防御关使用自己的同向进入与尾追脱离规则。

让敌机始终维持接近玩家的速度可以防止超越，但低速远距追近会拖长数分钟，因此只按近距预计交会时间逐渐调整，不在远处一律匹配 94% 空速。

## Consequences

玩家可以从尾后追进机炮包线，并在连续观察、调整瞄准后点射。敌机在这段近距窗口内降低了转向挑战；兵种的耐久、武器与正常交战差异继续保留。速度倍率较高时同向脱离仍慢于玩家，持续加力或长时间不开炮最终仍可能超越目标。

高速弹道的世界速度随发射时的载机速度改变，旧版以固定 720／820 m/s 报告的新版世界速度成为历史数据。相对出膛速度及机炮和导弹的快慢关系保持清楚，原入口与敌方武器保持原速度。

历史审计：本篇与[飞行舒适度](../feature/2026-11-21-flight-comfort.md)、[俯瞰可玩性](../feature/2026-11-21-top-view-playability.md)和[武器落点及遮挡](2026-11-22-hull-overlay-occlusion.md)部分重叠。前三篇保留操纵、画面和旧入射反馈的独立理由；本篇接管防御关近距航线及新版高速离架速度合同，不复制设置或渲染所有者。

## Verification

- `tools/test_sky_defense_combat.mjs`：100／500／1500 节、无人机／战斗机六组，用真实飞行和弹道在 566 米等待两秒后开火，必须命中同一敌机；同时覆盖运输机诱饵、投放、地面火力和机动约束。
- `tools/test_sky_pursuit.mjs`：高速弹体相对载机继续向前飞，机炮相对出膛速度保持 720 m/s，导弹上限相对发射载机为 1000 m/s。
- `tools/verify_sky_wingman.mjs`：自然生成的防御敌机，不改双方位置、姿态或耐久，以真实 A/D/W/S 和 F 输入追入 566 米，等待两秒后验证机炮命中并记录时间序列、截图。
