# Agent Note: 补齐新版干扰弹按钮

Status: implemented

## Problem

新版底栏漏掉干扰弹，玩家只能使用没有显示在操作栏的 C／X 快捷键，触屏也缺少发射入口。

## Decision

`00_shell.html` 在导弹旁增加「C 干扰弹」按钮，`65_app.js` 沿用现有离散操作绑定，调用共享 `tryFlares()`。按钮显示实际余量、冷却倒计时或用尽状态，并在当前规则不允许投放时禁用；读屏名称同时提供余量与冷却。原有 C／X、7 秒冷却和一次六颗效果保持同一实现。

## Alternatives considered

仅补充快捷键说明可以让键盘用户找到操作，但触屏仍不能投放，因此直接补上现有操作栏缺少的同类按钮。

## Consequences

按钮只承担发射入口和状态反馈，没有复制战斗逻辑或新增控件层。现有适配层回归验证真实投放、库存／冷却、暂停与待命禁用，以及点击不穿透；三尺寸 Chrome 验收检查原生鼠标、触屏、键盘激活与布局。结果见 [验收记录](../../../../sky-patrol/VERIFICATION.md)。
