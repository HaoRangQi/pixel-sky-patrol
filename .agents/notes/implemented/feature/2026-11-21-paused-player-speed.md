# Agent Note: 新版暂停调速与旧入口默认速度

Status: implemented

本记录对应首轮暂停调速。下文 218／397 节是首轮读数，不是新版当前默认。新版的 300 档对应原 100 节实速；巡航与加力的共同刻度和保留档差、1200 档满转向以及实际加速响应见[飞行舒适度与档位](2026-11-21-flight-comfort.md)。原入口默认和本页参数所有权仍有效。

## Problem

玩家需要调整飞机速度。新版和原入口共用飞行引擎，直接修改速度常量会同时改变两个入口，也会失去随页面保留、暂停修改和恢复平滑过渡的边界。

## Decision

新版 `sky-patrol/65_app.js` 持有当前页面的巡航／加力参数，单位在界面为节、引擎为 m/s。主界面「设置」和飞行暂停共用一个模态面板；主界面以 `pausedFrom: 'title'` 进入现有暂停状态，冻结待命演示。起飞前只保存配置，不把参数写进演示飞机；正式起飞和重开以所选巡航速度开始。飞行暂停时将参数写入正式玩家的可选 `cruiseSpeed`／`burnSpeed`。刷新页面恢复默认。

共享 `src/40_game.js` 读取玩家参数；没有参数的原入口继续使用精确的 112／204 m/s。暂停设置不写实际 `speed`，恢复后复用既有加力加速度和巡航阻尼。实际速度高于下调后的上限时平滑减速。HUD和位移始终读取实际速度。

界面显示约 218／397 节，但打开弹窗和恢复默认都不从取整后的数值反推引擎值。两项原生 range 的方向键由浏览器处理；暂停捕获按键，阻止飞行输入积累，保留 M 音效快捷键，恢复时清空输入和隐藏控件焦点。短横屏弹窗允许原生纵向滚动，祖先舞台在模态期间也允许 `pan-y`。

从主界面打开时标题为「设置」，关闭按钮为「返回主界面」，隐藏并禁用重新出航／返回待命；Esc 同样返回主界面并将焦点交回设置按钮。飞行中仍显示「航程暂停／继续飞行」，使用原有恢复路径。未增加游戏状态或第二套配置。

默认座舱表盘保持原量程；设定加力超过 450 节时扩大量程并在盘面显示 `KT/上限`。数字窗仍显示实际节数。

## Alternatives considered

飞行中直接加减速可以即时控制空速，但会增加操纵键和触屏操作。用户确认采用暂停菜单分别调参，保留 Shift 加力。

直接调整共享常量改动更少，但会同时改变旧入口和待命演示，也无法支持同页面的新航次设置，因此只为新版正式玩家携带可选参数。

## Consequences

速度设置不引入持久化、配置文件或新的公开产品 API。原速度常量继续承担原入口与默认行为，页面参数只有新版适配层一个所有者。适配层增加速度设置与焦点规则，现有测试的 DOM 夹具需要包含新控件。

设计和范围见 [暂停调速设计](../../../../docs/superpowers/specs/2026-11-21-sky-flight-speed-design.md)。[Node 行为测试](../../../../tools/test_sky_speed.mjs)覆盖默认逐帧兼容、暂停不变、连续速度、燃油、精确恢复、生命周期和输入；[独立 Chrome 验收](../../../../tools/verify_sky_speed.mjs)覆盖原生方向键、触屏、焦点与短横屏滚动，结果见 [浏览器记录](../../../../shots/sky_speed_results.json)。
