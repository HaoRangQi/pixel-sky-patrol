# Agent Note: 以移动玩家为中心的环绕伴飞

Status: implemented

## Problem

用户明确要求“我是太阳，他是卫星”，僚机要围绕玩家伴飞。旧实现把玩家后侧固定槽叠上正弦偏移，再让僚机追逐该移动位置，没有加入玩家的前进速度；目标点看似绕行，实际飞机却大多落后。100 节的 90 秒回归只覆盖右方和后方，500／1500 节接近一半时间在正后方。资源限制和独立选敌已具备，问题在伴飞运动目标的所有者。

## Decision

`44_ai.js` 使用约 180 米的水平环、比玩家高 26 米的伴飞高度。`wingmanOrbitVelocity` 输出玩家当前真实速度、环绕切向速度与有界径向校正的和；切向速度取 `min(42, 玩家速度 × .55)`，不再追一个在世界前移的机尾槽。出生位于玩家侧方，速度从当前前进速度加切向量开始，沿原转向、阻尼与前向积分连续飞行，不直接设置每帧环上坐标。

没有敌人、保持伴飞或停火时使用同一个环绕航线。偏离过远时仍用真实运动归队。补给改到约 320 米的外围环，高 60 米，继续等待 18 秒且至少六秒未受击；交战、攻击后脱离、低盾／空弹和损毁保留原优先级。操作栏把 `patrol` 显示为「环绕伴飞」。80 护盾、36 发、600 米低输出火力、1500／1800／2200 米交战范围和开关防刷均沿用[资源合同](2026-11-23-gun-sight-wingman-resources.md)。

环绕用世界水平径向与切向，随玩家位置平移；不会把玩家滚转、桶滚或倒飞直接当成僚机的位置变换。地形安全线与避让仍可改变实际航线，高速急转允许有限归队过程。

## Alternatives considered

继续扩大正弦偏移最省改动，却没有解决移动中心的速度前馈，仍会让僚机滞后在机尾。固定侧前槽可避免正后方，但不会形成用户要求的四周伴飞。

直接将实体贴在圆周上能得到漂亮轨迹，却会绕过速度、转弯和地形，受击及弹体碰撞也会随瞬移失真；因此只改期望运动，复用实际飞行积分。

## Consequences

僚机会连续经过前、左、后、右，允许短暂从后方绕过，交战时仍能离开去截击。它不会保证始终处于追尾画面中央，屏外友军方向与雷达沿用原提示。伴飞会随环绕方向加减速，交战的射速、库存和伤害没有提高。

移除 `follow/regroup` 固定机尾槽与 `patrolPhase`，不保留两套默认伴飞。飞行、资源和高层命令仍归 `44_ai.js`；本轮只加一个短速度函数，没有行为树、独立计时器、网络轮询或后台服务。

历史审计：[僚机接入](2026-11-23-wingman-ai-link.md)继续持有阵营、击杀信用和网络生命周期；[资源合同](2026-11-23-gun-sight-wingman-resources.md)继续持有护盾／库存／补给与交战。两篇侧前巡弋和侧后补给的旧移动位置理由由本篇取代。

## Verification

真实实体 90 秒、100／500／1500 节均覆盖四象限，正后方占比约 26.4／26.4／24.5%，采样距离约 176–206 米。转向、爬升、加力与补给的组合回归距离约 152–330 米，逐步位移等于当前速度积分，没有瞬移归位。

Chrome 的独立 60 秒航次覆盖四象限，距离 181.9–188.1 米，正后方占比 17.5%；真实 D 转向、Shift 加力后回到约 187.8 米。该航次仅将玩家／僚机高度抬到 1500／1526 米以避开地形，不改水平位置、姿态、速度或每帧运动。另由正常第一关验收确认僚机仍可截击、开火、拉开与受资源约束。实际截图、报告与完整回归见[验收记录](../../../../sky-patrol/VERIFICATION.md)。
