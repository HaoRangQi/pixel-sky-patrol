# Agent Note: 500节速度、持久倒飞与座舱舒适操纵

Status: implemented

## Problem

用户感受不到调参和 Shift 加速差别，并认为座舱 A/D 和鼠标转向过急，要求 500 节上限、持久180°倒飞、默认关闭鼠标方向和敌机调速。

诊断确认速度一直进入真实位移，但旧巡航阻尼使90%响应需4.19秒，巡航提高后还可能与加力上限相等，使 Shift 只耗油而不加速。原普通座舱 D 按0.25秒已倾斜约47°，稳定航向速度接近70°/秒。

## Decision

新版页面参数仍由 `65_app.js` 持有。巡航与加力上限最高500节，默认巡航精确112 m/s、加力500节；优先保持50节加力余量。到500节巡航时明确显示已达上限，禁用无可调范围的加力滑块，并停止没有速度增益的加力燃烧。新版巡航收敛系数为1.6，约两秒完成目标差的96%。实际速度继续用于世界位移与仪表。

共享 `40_game.js` 读取玩家可选的 `speedResponse`、`mouseSteering`、`cockpitComfort` 与 `inversionRoll`，无配置的旧入口保留原公式。鼠标默认不驾驶，瞄准／开火、键盘和触屏不受此开关限制。座舱普通倾斜限约32°，滚转速率0.6 rad/s、航向速率0.38 rad/s；真实模型、相机、仪表与挂载共用同一姿态，不单独拖慢镜头。

半滚手势由适配层键盘边沿检测：同方向长按至少2秒，松开后1.2秒内双击、间隔不超过0.35秒。1.6秒缓动的 `inversionRoll` 加在原倾斜上，完成后保持正／倒飞，下一次同法切换。原 Q 的 `spin` 仍完成360°并回到当前正／倒飞基线。暂停、失焦、重开清空待触发手势，自动重复不计双击。

倒飞与正飞的相机上轴接近相反，旧 `up` 线性插值在过渡中点会突然翻转。新版舒适配置下以四元数球面插值完整朝向，保留正交基和连续过渡；每次过渡只在开始时选弧，后续保持端点四元数符号连续，避免近180°时浮点符号改变使旋转中途换边。原入口继续原过渡合同。同时长按A、D时清空半滚手势，不能将零横向输入识别为同方向长按。

敌机速度使用单一 `G.enemySpeedScale`，新版默认0.65，暂停可调0.3–1.2。`42_combat.js` 仅在出生初速和最终目标速度应用倍率，现有阻尼平滑收敛；不缩放整段时间或武器速度。

## Alternatives considered

改变FOV、抖动或场景尺度可以制造加速感，但会加重眩晕且让视觉和真实位移不一致，因此保留稳定视野，修正参数余量、响应和实际加力目标。

只给座舱相机加低通能保留原操纵，却会令瞄准和仪表与机身运动分离，因此限制实际普通倾斜／航向变化，主动半滚使用独立的缓动分量。

敌机整体缩放 `dt` 改动少，但也会改变攻击频率、感知与能量计时，因此只缩放敌机速度。

## Consequences

此决定部分取代[首轮暂停调速](2026-11-21-paused-player-speed.md)的默认加力、600节上限与鼠标默认合同；参数仍只保留到刷新，没有增加持久化或另一套飞行模拟器。共享飞行文件已有超过800行，本轮只在原速度／姿态段增加可选配置，页面设置和手势仍归既有适配层。

验收见 [飞行操作记录](../../../../sky-patrol/VERIFICATION.md)、[舒适度浏览器数据](../../../../shots/sky_comfort_results.json)和[暂停三尺寸数据](../../../../shots/sky_comfort_speed_results.json)。100/500节相同4秒实飞位移分别约206/1029米，默认Shift三秒达到500节；座舱同姿态连续取样、A/D两方向半滚与误触、鼠标开关、触屏和敌机速度均有实际输入验证。
