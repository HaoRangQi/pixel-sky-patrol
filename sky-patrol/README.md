# 天际巡航 / SKY PATROL

本目录是推荐的新版入口。驾驶先进战机守卫秋日湖谷，或选择湖岸巡航、秋林低飞。飞行中可切换追尾、座舱和北向俯瞰。

[项目介绍、快速开始与完整操作表](../README.md) · [新版游戏](index.html) · [验收记录](VERIFICATION.md)

## 运行与构建

使用支持 WebGL2 的现代浏览器打开本目录的 `index.html`。也可按根 README 启动静态服务，再访问 <http://127.0.0.1:8765/sky-patrol/>。

以下命令均在仓库根目录运行，推荐使用 Node.js 24，无需安装 npm 依赖：

```bash
node sky-patrol/build.mjs
```

构建复用 `src/` 中的世界、飞行、渲染和战斗模块，加入本目录的外壳、湖谷场景、机体、仪表和适配层，生成自包含的 `sky-patrol/index.html`。脚本、样式和 SVG 均已内联；开发时修改源文件后重新构建。

根目录的 [index.html](../index.html) 保留旧美术入口，也接收共享引擎修正。未改动的旧 UI 归档位于分支 `feature/sky-patrol-ui` 的提交 `37167ae`。

## 当前玩法

- **守卫湖谷**。三关依次拦截无人机、战斗机，以及大型运输机与它的混合护航队。运输机能投放会移动和攻击的装甲车，并用有限干扰弹诱开导弹。清除空中敌机和已空投装甲后查看成绩，可继续迎击空中增援。
- **战斗难度**。设置里可选轻松、标准或挑战，默认标准；每关编制为 4／5／6、6／8／10、8／10／12 架。无人机、战斗机、运输机的干扰弹默认分别为 1／2／3 发，诱骗率为 45／65／75%，也可逐项调整。敌机被尾追一段后会先显示脱离预兆，再侧脱并重新压回攻击；HUD 显示每架敌机剩余干扰。
- **自由飞行**。自由巡航从南岸湖区出发，秋林低飞从东侧草谷出发。空格或视角按钮切换视角，巡航时还可使用斜后追踪。
- **辅助僚机**。主界面点击「设置」，或起飞后按 Esc，开启「辅助僚机（本地 AI）」。默认关闭；以你为中心在约 180 米周围环绕伴飞，有敌情时自主选敌、截击再返回。80 护盾、36 发机炮；缺弹或低盾后在约 320 米外围等待 18 秒补给，损毁则本航次退出。模型服务是另一个可选开关，完整范围和补给规则见[僚机使用说明](../README.md#带一架辅助僚机)。重开保留配置，刷新后关闭并清空配置。
- **设置**。主界面点击「设置」可在起飞前调参，按 Esc 或「返回主界面」关闭；飞行中 Esc 打开暂停菜单。巡航从 300 档起（原 100 节实速）；500 档起读数与实速一致。巡航和加力用同一刻度：默认 300／500，调巡航会保留两者的档差，上限 1500。飞行中按住 Shift，默认 0.85 秒可拉到 500 节。自动转向在 800 档为 80°/秒，1200 档才满 120°/秒；取消「转向随速度自动适配」即可独立设置 8–120°/秒。敌机按你的空速和转弯半径调整，默认倍率 65%；被从尾后追近时同向脱离，近距最高不超过玩家当前空速的 95%。音量滑轨 0–100%，默认 55% 等于原默认听感。重开和切换航程保留设置，刷新后使用默认值。
- **飞行与倒飞**：WASD／方向键或触屏摇杆控制飞行。鼠标控制方向默认关闭，瞄准、左键开炮仍可用；可在暂停菜单开启鼠标驾驶。按住 A 或 D 至少 2 秒后松开，在 1.2 秒内双击同一个键，两次点击间隔不超过 0.35 秒，飞机将在 1.6 秒内翻转 180°并保持倒飞；重复操作可翻回。Q 仍执行完整桶滚，回到当前正飞或倒飞姿态。
- **使用武器**。追尾／座舱准星略高于中心，机炮从真实机鼻炮口射出，近弹沿真实路径接近以 900 米为基准的瞄准线，不在准星处凭空生成。白金亮弹头和短曳光显示实际飞行，平直时间按 900 米和发射世界速度换算，超程后下坠，弹迹不在机尾积成残线；移动目标可参照淡蓝相对提前量小圆。机炮 180 发，打空后 10 秒补满。锁定捕获半径为 38 个逻辑像素，俯瞰为 47.5，保持仅多 18%；目标确认环约缩小一半。淡蓝色表示锁定中，金色「已锁定」时按 E 可发射追踪导弹，转出保持圈则为无锁弹。C／X 或底栏「C 干扰弹」按钮投放干扰弹，按钮显示余量及 7 秒冷却。
- **回正与找敌**。R 或底栏「R 回正」用 1.6 秒平滑恢复水平正飞。俯瞰屏外箭头显示方向与距离，座舱的「跟踪」提示还会显示敌机相对高低。两条翼尖线在低速平飞时持续生成。
- **上下瞄准**。按住 W / S 调整俯仰，松开时保持角度。追尾、俯瞰与座舱都逐渐进入转向，R 可恢复平飞。

## 开发与验收

基础检查同时构建新旧入口，执行 Node 回归并检查补丁格式。完整回归也包含 Chrome／WebGL2 探针，需要下述浏览器环境：

```bash
node build.mjs && node sky-patrol/build.mjs && node --test tools/test_*.mjs && git diff --check
```

僚机与 AI 接入验收自带临时静态服务和模拟接口，无需真实 Key 或已有服务：

```bash
node tools/verify_sky_wingman.mjs
```

报告与桌面三视角、手机横竖屏截图写入 `shots/sky_wingman_*`，覆盖本地僚机、AI 配置、失败回退、取消请求和设置生命周期。实际外部模型服务还需允许 CORS。

俯瞰、回正与落点反馈验收入口：

```bash
node tools/verify_sky_playability.mjs
```

运行 `verify_sky_playability.mjs` 前，需要已有静态服务在 `127.0.0.1:8765` 提供仓库根目录。两种验收脚本都使用独立无头 Chrome 配置；当前工具将浏览器路径固定为 macOS 默认的 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`，使用 Node.js 24 运行。游戏本身不依赖 macOS；其他系统运行这些浏览器工具需要调整 Chrome 路径。

湖谷由 Blob Worker 生成，脚本会等待真实的 `window.__PI.ready()`，不能以固定延时替代就绪判断。新增浏览器用例也应检查就绪、页面异常与实际断言结果。

机炮连续帧验收使用已有 8765 预览，记录自然飞行与高空超程夹具，检查前方亮头、机尾残线、松开清理、转向下坠及三种尺寸；结束后关闭专用 Chrome：

```bash
node tools/verify_sky_gun_tracers.mjs
```

截图和实测数据默认写入 `shots/sky_gun_muzzle_*`，包含实际出生点、近段收敛、窄锁圈原生转向／越界发射和超程亮头；`--prefix=sky_lock_muzzle` 可指定证据前缀，加 `--baseline` 时输出到 `shots/sky_gun_tracer_before_*`。自然追入机炮射程并命中、60 秒四方位环绕伴飞的验收由 `verify_sky_wingman.mjs` 负责。

俯瞰敌情、翼尖尾线、R 回正、W / S 持角、落点视觉和低帧率加速均有浏览器用例。手机尺寸由 Chrome 模拟。最新测量和历次媒体见 [验收记录](VERIFICATION.md)。
